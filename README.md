# Rastreio Magalu 📨

Formulário simples para rastrear pedidos transportados pela Magalog (Magazine Luiza).

## Como usar

1. Acesse: [https://seu-usuario.github.io/rastreio_magalu](https://seu-usuario.github.io/rastreio_magalu)
2. Digite o código de rastreamento fornecido no momento da compra
3. Clique em "Rastrear Pedido"

## Lojas que usam a Magalog

- Magazine Luiza
- Kabum
- Netshoes
- Zattini
- Centauro
- E outras lojas do grupo

## Como funciona

O formulário redireciona para a página oficial de rastreamento:
```
https://cademinhaentrega.com.br/magalog/tracking/P/{CÓDIGO}
```

---

**Nota:** Este projeto não é oficial. É apenas um atalho para facilitar o acesso ao sistema de rastreamento da Magalog.
